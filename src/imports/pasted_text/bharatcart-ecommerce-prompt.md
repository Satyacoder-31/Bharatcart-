# Figma AI Prompt — Indian Multi-Vendor E-Commerce Marketplace

Design a **complete, production-quality Indian multi-vendor e-commerce marketplace website and mobile-responsive UI inspired by the shopping experience of Meesho**, but **do not copy Meesho's logo, exact branding, proprietary assets, or copyrighted visual elements**.

Create an original marketplace brand called **“BharatCart”** with a modern, trustworthy, affordable Indian shopping experience.

The design must feel like a real large-scale e-commerce platform, not a simple UI concept.

* Vendors can sell products
